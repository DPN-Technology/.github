# Release Checklist

## Identity

- [ ] Version/tag selected
- [ ] Source commit recorded
- [ ] Target platforms documented
- [ ] Release date recorded

## Build

- [ ] Clean build completed
- [ ] Release artifact produced
- [ ] Artifact corresponds to recorded source revision
- [ ] Checksums generated where appropriate
- [ ] Signatures generated where appropriate

## Verification

- [ ] Automated tests passed
- [ ] Relevant manual verification completed
- [ ] Runtime smoke test completed
- [ ] Upgrade/migration path tested when applicable
- [ ] Known limitations documented

## Security

- [ ] Dependency/security checks reviewed
- [ ] New privileges reviewed
- [ ] New listeners/endpoints reviewed
- [ ] Secrets/configuration changes reviewed
- [ ] Third-party license records updated

## Operations

- [ ] Install/upgrade instructions current
- [ ] Monitoring/health behavior documented
- [ ] Backup or migration requirements documented
- [ ] Rollback/recovery path documented

## Release

- [ ] Release notes written
- [ ] Artifacts attached
- [ ] Checksums/signatures attached where applicable
- [ ] Version references updated
- [ ] Post-release verification completed
