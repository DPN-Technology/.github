# DPN Technology Organization Configuration

This repository powers the public GitHub organization profile and provides reusable community-health defaults for DPN Technology repositories.

## What lives here

| Path | Purpose |
| --- | --- |
| `profile/README.md` | Public DPN Technology organization overview |
| `assets/` | Organization profile visuals |
| `SECURITY.md` | Organization-level vulnerability reporting guidance |
| `CONTRIBUTING.md` | Default contribution expectations |
| `CODE_OF_CONDUCT.md` | Public collaboration standards |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull-request structure |
| `.github/ISSUE_TEMPLATE/` | Default public issue forms |

## Design rule

This repository is **presentation and organization policy infrastructure**. It should not be used to publish secrets, private repository inventories, credentials, internal network information or unverified capability claims.

## Public profile

GitHub renders [`profile/README.md`](profile/README.md) on the DPN Technology organization overview page.

## Security

For vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not disclose exploitable issues in a public issue.
