# DPN Technology Support

Support is handled in the repository that owns the affected public project.

## Bugs and feature requests

Use that repository's issue tracker and select the appropriate issue form.

## Security issues

Do **not** open a normal public issue for a vulnerability. Use the repository Security tab and private vulnerability reporting where available, and follow [SECURITY.md](SECURITY.md).

## Private projects

Private DPN projects are not supported through public GitHub issues unless the project is intentionally published with a public support path.
